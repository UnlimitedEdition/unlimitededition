## 🧭 About / O meni

**EN** — Full-stack developer from Serbia. I build and run **production SaaS** (product-expiry tracking
for retail, invoicing with SEF e-invoicing, online booking) on **Next.js + Supabase**, custom websites and
web apps for clients, native **Android apps** (Kotlin, Jetpack Compose) and **security / GDPR tooling**.
Everything from Postgres/RLS, edge functions and FastAPI backends to PWAs, React Native and multilingual,
SEO-ready sites. Open to **freelance work and collaboration**.

**SR** — Full-stack developer iz Srbije. Gradim i održavam **produkcione SaaS** aplikacije (praćenje
rokova trajanja u maloprodaji, fakturisanje sa SEF-om, online zakazivanje) na **Next.js + Supabase**,
sajtove i web aplikacije po meri za klijente, **Android aplikacije** (Kotlin, Jetpack Compose) i
**security / GDPR** alate. Radim kroz ceo stack — od Postgres/RLS, edge funkcija i FastAPI backenda do
PWA, React Native i višejezičnih, SEO spremnih sajtova. Otvoren za **freelance i saradnju**.

## ⭐ Featured / Izdvojeni projekti

### 🏪 Protokol Alert · u produkciji od 04/2026 · v1.2.0

[![live](https://img.shields.io/badge/live-protokolalert.rs-2ea44f)](https://protokolalert.rs)

**EN** — Multi-tenant SaaS that tracks product-expiry dates in retail: worker PWA with barcode/QR scanning
and PIN sign-in, admin panel (stores, suppliers, PDF/Excel reports, billing with IPS QR), backend API with
automatic expiry checks and an Android app. Tracks ~3,300 products in production.
**SR** — Multi-tenant SaaS za praćenje rokova trajanja u maloprodaji: aplikacija za radnike (PWA) sa
skeniranjem i PIN prijavom, admin panel (prodavnice, dobavljači, PDF/Excel izveštaji, naplata sa IPS QR),
backend API sa automatskim proverama rokova i Android aplikacija. U produkciji prati ~3.300 proizvoda.
`TypeScript · Next.js · Express · Supabase · Expo`

### 🧾 [fakture-online](https://github.com/UnlimitedEdition/fakture-online)

**SR** — Fakturisanje za freelancere, paušalce i male firme u Srbiji: faktura za ~30 sekundi, šalje se kao

uparivanje bankarskih izvoda.
`TypeScript · Next.js · Supabase`
