PWA sa QR skeniranjem. Custom JWT/RBAC, podaci po organizaciji, `pg_cron` poslovi, web-push i FCM.
`TypeScript · Next.js · Express · Supabase`

### 🧾 [fakture-online](https://github.com/UnlimitedEdition/fakture-online) · live demo

**SR** — Online fakturisanje za freelancere, paušalce i male firme u Srbiji: profesionalna faktura za

`TypeScript · Next.js · Supabase`

gradi zajedničku community bazu barkodova. FastAPI backend + Expo (React Native) mobilna aplikacija.
